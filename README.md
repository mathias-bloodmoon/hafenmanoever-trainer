# Hafenmanöver-Trainer (SKS)

Interaktive Web-Simulation zum Üben von Hafenmanövern für den Sportküstenschifferschein (SKS):
Ablegen und Anlegen längsseits am Steg, in der Box mit Pfählen und mediterran mit Heck zum Kai
(Muringleine oder eigener Anker).

## Starten

`index.html` im Browser öffnen – kein Build, keine Abhängigkeiten.

## Funktionen

- Vier Bootstypen (Einzelruder hinter dem Propeller, Doppelruder neben dem Propeller, Langkieler, große Charteryacht) und frei konfigurierbare Bootsparameter
- Physik: Masse/Trägheit inkl. mitbewegtem Wasser, Rumpf- und Kielwiderstand, Propellerschub, Radeffekt, Propellerstrahl am Ruder, Ruder mit Strömungsabriss, Wind und Strömung
- Leinen per Klick von Bootsklampe zu Klampe, Poller, Pfahl oder Muringboje; elastisch, nur Zug – Eindampfen in Springs wird realistisch simuliert
- Kontakt mit Steg, Pfählen und Nachbarbooten (Fender-Modell)
- Kraftvektoren, Unterwasserschiff und Spur einblendbar

## Bedienung

| Taste | Funktion |
|---|---|
| W / S | Gashebel ±10 % |
| Leertaste | Neutral |
| A / D | Ruder Backbord / Steuerbord |
| C | Ruder mittig |
| Q / E | Bugstrahlruder |
| Entf | ausgewählte Leine lösen |
| [ / ] | Leine dichtholen / fieren |
| P / R | Pause / Neustart |

Hinweis: Lernmodell mit geschätzten Kennwerten, keine zertifizierte Simulation.
